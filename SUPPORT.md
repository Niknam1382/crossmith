# Support

Before asking, check whether one of these already covers it:

- **Docs:** [`docs/`](docs/) — getting started, guides, architecture
- **Troubleshooting guide:** [`docs/guides/troubleshooting.md`](docs/guides/troubleshooting.md)
- **Existing issues:** [search open and closed issues](../../issues)

## Ask a question

Use [GitHub Discussions](../../discussions) for "how do I…", ideas, and
general chat. It's searchable and helps the next person with the same
question.

## Report a bug

Use the [bug report template](../../issues/new?template=bug_report.yml).
Include your OS, Crossmith version, and (if possible) the project you were
trying to build — a minimal reproduction is the single most useful thing
you can attach.

## Report a security issue

**Not here — see [SECURITY.md](SECURITY.md).**

## Request a feature or a new language/platform adapter

Use the [feature request template](../../issues/new?template=feature_request.yml).
If you're proposing a new adapter, skim
[`docs/guides/adapter-development.md`](docs/guides/adapter-development.md)
first — it may already be scoped on the roadmap.
