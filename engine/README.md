# crossmith-engine

The Python core of [Crossmith](../README.md) — project detection, build
orchestration, and packaging. Runs as a loopback-only FastAPI sidecar
process spawned by the desktop shell.

See [`../CONTRIBUTING.md`](../CONTRIBUTING.md) for dev setup and
[`../docs/DECISIONS.md`](../docs/DECISIONS.md) for the architecture.
